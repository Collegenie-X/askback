## ① 가정통신문 — 🏫 기본용

> **[학교명] [학년] 정보 수업 — AI와 함께 생각하며 만드는 수업 안내**
>
> 이번 [학기 · 기간]에 [과목] 시간에 **AskBack**이라는 AI 코치를 사용합니다. AskBack은 학생에게 바로 답을 주기보다 *"그 숫자는 어디서 왔어?"* 처럼 **되물어서**, 학생이 스스로 문제를 정하고 기획서를 쓰고, 작은 웹 화면(MVP)을 만들어 보게 돕는 도구입니다.

| 궁금한 점 | 안내 |
|---|---|
| 무엇을 하나요? | [8]차시 동안 생활 속 불편 하나를 골라 기획서를 쓰고, 버튼이 동작하는 작은 웹 화면을 만들어 발표합니다 |
| 비용이 드나요? | **가정의 비용은 없습니다.** AI 사용료는 [학교 · 기관]이 부담합니다 |
| 회원 가입이 필요한가요? | **필요 없습니다.** 학생은 수업용 카드(QR)와 닉네임으로만 접속합니다. 이메일 · 전화번호 · 비밀번호를 만들지 않습니다 |
| 어떤 정보가 저장되나요? | 닉네임 · 학년 · 수업 중 대화와 기획서 · 만든 화면. **실명 · 연락처 · 얼굴 사진은 입력하지 않도록 지도합니다** |
| 대화는 어디로 가나요? | 학교가 운영하는 AskBack 서버에 저장되고, 답을 만들기 위해 AI 회사(Anthropic)의 API로 전송됩니다. [AI 회사의 데이터 처리 방침 요약 · 링크] |
| 누가 볼 수 있나요? | 학생 본인과 담당 교사 |
| 언제 지우나요? | [학기 종료 후 ○개월]에 삭제합니다. 학생은 그 전에 자기 기록을 파일(.md)로 내려받을 수 있습니다 |
| 어떻게 평가하나요? | 완성도보다 **생각의 과정**(스스로 정한 기준, 고친 횟수와 이유, 친구에게 준 질문)을 봅니다 |
| 문의 | [담당 교사 · 연락처] |

## ② 신청서 — 🚀 심화용 (희망자)

> 기본용을 마친 학생 중 희망자는 [방학 · 동아리]에 **실제 사용자가 쓰는 서비스**로 발전시키는 심화 과정에 참여할 수 있습니다.

| 항목 | 안내 |
|---|---|
| 기간 · 시간 | [4주 · 주 4일 × 3시간] |
| 참여 조건 | 기본용 수료 + 🚦 심화 관문 통과 (교사 확인) |
| 사용하는 도구 | AskBack + 유료 AI 코딩 도구. **유료 도구 계정과 결제는 [교사 · 조교 · 기관] 명의**이며 학생 개인 계정을 만들지 않습니다 |
| 비용 | [무료 · 재료비 ○원] |
| 만들어지는 것 | 공개 주소로 접속되는 웹 서비스 · 실제 사용자 5명 이상 · 1주 운영 기록 |
| 공개 범위 | 서비스는 [학교 안 · 일반 공개]로 배포됩니다. 서비스에서도 사용자의 실명 · 연락처를 받지 않습니다 |
| 보호자 동의 | ☐ 참여에 동의합니다 ☐ 만든 서비스를 [범위]에 공개하는 데 동의합니다 |
