## 3. 기획자가 이 영상에서 증명하는 5가지

| # | 개념 | 영상 속 대사 | 왜 세나 |
|---|---|---|---|
| 1 | **문제 깎기** | "'AI를 잘 쓰고 싶다'는 문제가 아니라 소원이더라고요" | 중학생 영상에서 거의 안 나오는 말. 여기서 심사위원이 고개를 든다 |
| 2 | **관찰 → 번역** | "선생님은 2시간 걸려요. 그래서 대화 안에 넣었어요" | 남의 해결책을 **내 조건으로 번역**한 흔적 |

## 4. 확장 질문 — 아이디어를 키우는 질문들

> **좁히는 질문**(02~05)이 아이디어를 내 것으로 만들었다면, **확장 질문**은 그 하나를 다음 계단으로 올립니다.
> ⚠️ 확장 질문은 **1단을 끝낸 뒤에만** 유효합니다. 끝내기 전에 던지면 그냥 공상이 됩니다.

| 계단 | 확장 질문 | AskBack에서의 답 | 여는 방향 |
|---|---|---|---|
| **1→2단** | "같은 걸 또 하고 싶어지려면? **기능 말고 만나는 방법**을 늘리면?" | 되묻기를 두 겹으로 — 답 끝의 **열린 되묻기** + 질문 두 번마다 **5초 확인** | 반복인데 잔소리가 아니다 |
| **1→2단** | "**못한 것 · 안 한 것**만 따로 모으면?" | 순서도 · 핵심 · 차별점 · 실패 조건 **4칸 중 빈 칸**만 보여주기 | 학생마다 다른 목록 = 개인화 |
| **2→3단** | "사용자가 **자기 말**을 넣을 칸은 어디? 딱 한 칸만 만든다면?" | **기획서.md** — AI 문장 복붙이 아니라 내 말로 채우는 칸 | 내가 쓴 건 설명할 수 있다 = 애착 |
| **3→4단** | "내가 고른 재료가 **사용자도 만들 수 있는 재료**인가?" | 글자 한 장(.md). 영상·캐릭터는 회사만 만든다 | 만든 걸 남에게 주고 싶어진다 |
| **3→4단** | "**서버 없이** 나눌 방법은?" | 기획서.md 파일 하나를 선생님·친구에게 | 커뮤니티 = 서버가 아니다 |
| **4→5단** | "지금 **손이 제일 오래 걸리는 곳**은?" | 열 번 질문한 걸 되짚어 보는 일 → **10문 리포트 자동 생성** | **여기가 AI 자리** |

### 영상에서 확장 질문 쓰는 법 (07번 18초 안에)

전부 말하면 안 됩니다. **계단 종이를 손가락으로 짚으면서 질문만 소리 내어** 던지세요.

> "2단은 제가 정한 게 아니에요. **매번 물으면 잔소리 아닌가?** 여기서 나왔어요. 그래서 두 번에 한 번, 5초로요.
> 3단은 **쓰는 사람이 자기 말을 넣을 칸이 어디지?** 에서 나왔고요.
> 5단이 AI인 이유는 딱 하나예요. **손이 제일 오래 걸리는 데가 거기**였어요."

**말하는 법 3가지**
1. 질문을 **소리 내어 그대로** — 심사위원 귀에 남는 건 답이 아니라 질문이다
2. 질문 하나에 **답 한 줄**만. 설명 붙이면 늘어진다
3. 계단 종이를 **손가락으로 짚으며** — 시선이 종이로 갔다가 다시 렌즈로

```
❌ AI를 잘 쓰는 법을 배우고 싶다   ← 소원
⭕ AI는 답만 주고
   아무것도 안 물어본다           ← 문제

**② 네 가지 질문 (04번)**
```
🟡 순서도    "화면 닫고, 순서도 그려 봐"
🟣 핵심      "한 줄만 남긴다면 어디? 왜?"
🩷 차별점    "다른 방법이랑 뭐가 달라?"
🔴 실패조건  "이거 언제 안 돌아가?"

```

**③ 1단 화면 한 장 (05번)**

│  [ 질문 쓰는 칸 ]   │
│   ↓               │
│   답 (끝까지)       │
│   🙋 되묻기 한 줄    │
└──────────────────┘
🚫 점수판  🚫 로그인  🚫 캐릭터
```

**④ 계단 5칸 (07번)**
```
5단  AI — 10문 리포트 자동 생성      ← 손이 제일 아픈 곳
4단  나눔 — 기획서.md 파일로 선생님께
3단  메이커 — 내 말로 채우는 기획서 한 장
2단  두 겹 되묻기 (두 번에 한 번, 5초)
1단  화면 한 장 ✅ 끝냄
```

## 8. 화면 녹화 컷 (02번)

AI의 첫 대답이 **넓다는 걸 눈으로** 보여주는 컷입니다.

- 실제로 AI에 물어본 화면을 **스크롤하며 녹화** (길게 쭉 내려가는 게 포인트)
- 편집에서 **2배속**으로 내리고, 끝에서 **화면 축소 → 기능 열 개가 한눈에**
- 그 위에 노란 자막 한 줄: **"다 맞는 말. 근데 내가 정한 건 없음"**
- 개인정보·계정 이름이 보이면 **가리기**

## 11. 편집 순서

1. **실사 컷만** 먼저 붙여서 말이 이어지는지 확인 ← 뼈대
2. 화면 녹화(02) → 손글씨 컷(03·04·05·07) → 클링은 마지막에 얹기
3. **총 길이 1:00 초과 / 3:00 미만** (2:20 근처)
4. 자막: 화면 아래 큰 글씨, **한 줄 12자 이내**, 말한 그대로
5. 노란색 강조: **한 반에 2시간 · 320 / 610 · 1단 화면 한 장**
6. 배경음악은 목소리보다 확실히 작게
7. 엔드카드 3초: `학교 · 학년 · 이름 · 지원 역할: 기획자`
8. 유튜브 **일부공개** → URL 복사 → **자막 추출해 지원서 입력**

## 12. 대본 만드는 법 (제일 중요)

**쓰지 말고, 말해라.**
1. 이 문서를 덮고, 친구한테 **2분 동안 말하듯 녹음**
2. 녹음을 그대로 받아 적기
3. **내가 진짜 쓴 단어만** 남기고 다듬기

자막이 지원서에 그대로 들어가니까 **문장을 끝까지 맺는 것**만 신경 쓰자. ("~했어요." "~였어요.")
