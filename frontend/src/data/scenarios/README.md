# 예시 시나리오 JSON — 한 장이 예시 프로젝트 하나

`<id>.json` 한 장에 **질문 · 답 · 열린 되묻기 · 역질문 · 기획서 · 심화 · 10문 리포트**가 전부 들어 있다.
같은 JSON을 두 곳에서 쓴다.

| 어디서 | 어떻게 보이나 | 코드 |
|---|---|---|
| 메인 앱 `/` — ☰ 메뉴 · 설정 · 온보딩의 **📂 예시 프로젝트** | 대화 전체가 **한꺼번에** 펼쳐진 프로젝트로 열린다 (누를 것 없음) | `src/lib/example.ts` |
| `/demo` | 폰 목업 + 코칭 해설. 기본은 한꺼번에, [▶ 한 걸음씩]도 가능 | `src/components/demo/` |

## 새 예시 만들기

1. `smartpot.json`을 본보기로 `<id>.json`을 만든다. 스키마는 `src/components/demo/types.ts`의 `Scenario`.
   (`roles` · `chips`는 `common.json`에서 오니 넣지 않는다)
2. `index.ts`에 import 한 줄과 배열 한 칸을 보탠다.
3. 검사한다 — `python3 scripts/validate_scenario.py frontend/src/data/scenarios/<id>.json --full`

## 코칭 규칙 (검사기가 확인하는 것)

- **코드는 없다.** 답에는 규칙 카드 · 상태표 · 순서도(```` ```mermaid flowchart TD ````) · 데이터 한 줄의 모양 · 화면 칸 · 판정 기준 · 비교표 · 차별점만. 코드는 다른 도구로 뽑는다.
- **답하고, 되묻는다.** 모든 답은 `answer.ask` — 열린 질문 하나로 끝난다. 학생의 다음 질문은 그 되묻기에 자기 말(직접 잰 숫자 · 본 것)로 답하면서 시작한다.
- **질문은 20개 이상(본보기는 20개) — 리포트 2장.** 2문 1역 — 짝수 번째 답(2 · 4 · 6 …) 뒤마다 `reverseQuestion`. 방금의 알고리즘을 *진짜 아는지* 확인한다 — 순서도 따라가기("이때 ___면 다음은?"), 실패 조건, 검증, 핵심("하나만 남긴다면?"), 차별점. 일반 질문 금지.
- **리포트에는 제목이 있다.** `report.title`은 `"{프로젝트 이름} · 1번째 리포트"`(번호는 프로젝트마다 1부터), `report.headline`은 그 10문을 한 줄로 말하는 제목(예: "센서에서 공유까지 — 화분이 네 단을 올랐다"), `report.range`는 `"질문 Q1~Q10 · …"`. "판"이라는 말은 쓰지 않는다.
- **답 10개마다 리포트 1장.** `window: { startCount: 0, size: 10 }`. 1번째 리포트(`report`)의 숫자(mix · six)는 **앞의 10턴만** 센다. 11번째 질문부터는 2번째 리포트 구간 — 1번째 리포트의 미션(차별점 `___` 채우기)을 학생이 해 오고, 남에게 건네 보고, 며칠 써 보고, 실제로 터진 문제로 규칙을 고친다(v2 → v3). 16번째 턴은 전체 순서도 한 장, 17~20번째는 발표 · 건네기에서 들은 말로 한 번 더 고치고 다음 사람에게 넘기는 한 장으로 끝난다. 2번째 리포트의 글은 `report2`(title · headline · range · lastMission · mixComment · best · nextMission)에 적고, 숫자는 11~20번째 턴에서 코드가 직접 센다. **질문 길이는 일부러 섞는다**(40자 미만 · 40~119자 · 120자 이상) — 리포트의 글자 수 분석에 쓰인다.
- **작게 시작해서 한 단씩.** `stages` 5단(예: 규칙 → 메이커·센서 → 서버·모니터링 → AI 눈 → 공유·협력 → 써 보고 고치기). 대안 비교에는 '하지 않는다'도 한 줄로 넣는다. 다음 단은 코치가 아니라 학생이 말한 아쉬움에서 나온다 (`fromChip: expand` 의 ___ 빈칸).
- **기획서.md가 남는다.** 턴마다 `plan: { section, md }` 가 쌓인다. 맨 열린 질문(O5)처럼 내 프로젝트의 답이 아니면 `planSkip`. 역질문에서 학생이 정한 것은 기획서에 *(○○이 역질문에서 정함)* 으로 들어간다.
- **차별점은 학생이 쓴다.** 비교표의 틀은 코치가, 마지막 줄 `___` 은 학생이. 다음 판 미션이 된다.
